# Publication and citation

## How to cite

> Friedman, D. A. (2026). *Forensic Audit of the MillenniumLean Clay-Proof
> Package (AIX Global)* (version 1.0.0) [Report]. Zenodo.
> <https://doi.org/10.5281/zenodo.22243473>

BibTeX:

```bibtex
@techreport{friedman_millennium_audit_2026,
  author  = {Friedman, Daniel Ari},
  title   = {Forensic Audit of the MillenniumLean Clay-Proof Package (AIX Global)},
  version = {1.0.0},
  year    = {2026},
  doi     = {10.5281/zenodo.22243473}
}
```

`CITATION.cff` carries the same metadata in machine-readable form, and
`.zenodo.json` carries the deposit metadata including the GitHub
`related_identifiers` entry.
