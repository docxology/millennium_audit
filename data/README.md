# data/

Audit receipts and machine-readable records. Everything here was generated by
real execution during the 2026-09-01 audit session.

| File | Contents |
|------|----------|
| `audit_report.json` | Machine-readable audit: SHA-256 inventory, declaration/axiom/sorry counts, per-problem verdicts, headline |
| `audit_facts.json` | Registry-backed measured facts (used by the template evidence registry to support manuscript numbers) |
| `BUILD_RECEIPT.md` | Independent Lean kernel reproduction receipt (toolchain, mathlib pin, build/axiom output verbatim) |
| `STATEMENT_EVIDENCE.md` | Per-problem file:line gap analysis |
| `audit_run.log` | Console log of the audit orchestrator run |

Regenerate `audit_report.json` with `python3 scripts/run_audit.py`.
